00 — STRATEGY
Build Strategy — Why This Order

Every Excel user — from a first-day student to a veteran CA — uses the same 40–50 operations 90% of the time. Master these basics first. Domain-specific features (GST reconciliation, Tally cleanup) are built on top of this foundation. If CELLIX cannot reliably create a formula, sort a column, or explain a cell, no CA will trust it with their compliance work.

Tier 1 — Core Basics

Sheet/row/column operations, cell formatting, copy-paste, SUM/IF/VLOOKUP equivalents. Every single Excel user does these daily. Build these first — without them the product doesn't work at all.

7 feature groups~60 operationsWeeks 1–4

Tier 2 — Common Operations

Sorting, filtering, lookup formulas, text functions, date functions, conditional formatting. Used by 80% of users regularly. After Tier 1 is stable, build these before any domain features.

8 feature groups~70 operationsWeeks 5–8

Tier 3 — Intermediate

Error fixing, data validation, array formulas, pivot tables, charts. Used by power users and professional CA workflows. Build after Tier 2 — these are the bridge to domain-specific features.

8 feature groups~50 operationsWeeks 9–12
The Conversational Q&A layer runs across all tiers from Day 1 Every feature must have both a "do it for me" (action) and a "tell me about it" (explain) conversational interface. The Q&A layer is not a separate feature — it is the interface layer for every operation in every tier.

USER"Look up the state name from the GSTIN — the first 2 digits are the state code"
CELLIX
Proposed formula for column J: =INDEX(StateCodes!B:B,MATCH(VALUE(LEFT(C2,2)),StateCodes!A:A,0)). This extracts the state code from your GSTIN and looks up the state name. You'll need a StateCodes reference sheet — want me to create one?
USER"Why is my VLOOKUP in column D returning #N/A?"
CELLIX
The VLOOKUP in D2 is searching for value MT/2024/001 in column A of Sheet2. The issue is likely a trailing space or format difference. Try wrapping with TRIM: =VLOOKUP(TRIM(A2),Sheet2!A:C,3,FALSE). Approve to apply this fix?
CA Context: VLOOKUP is the #1 requested formula Indian CAs use VLOOKUP constantly for supplier master lookups, HSN code matching, and ledger cross-referencing. The most common failure is partial text matches (trailing spaces from Tally exports). Always suggest TRIM wrapping when VLOOKUP returns #N/A.

All Error Types to Handle

    #REF! — Invalid cell referenceTrace which cell was deleted that broke the reference. Suggest fix.
  • #VAL

  • #N/A

  • #DIV

User DescriptionGenerated FormulaVerification Check

The Golden Rule for Formula Generation Always use the actual column letters and header names from WorkbookContext — never hardcode A, B, C. If the user's amount column is column D, the formula uses D. If they rename it to column F next week, the formula must be regenerated using the current context. Never assume column positions.
